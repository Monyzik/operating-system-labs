## Лабораторная работа №2

### Создание процессов и взаимодействие через каналы

ФИО: Кобылкевич Фёдор Максимович

Группа: M8О-202БВ-25

Вариант: 12

### Постановка задачи

Разработать программу на языке Си. Родительский
процесс создаёт два дочерних процесса, представленных отдельными программами.
Родитель принимает строку произвольной длины, передаёт её первому ребёнку,
получает результат от второго и выводит его в стандартный поток вывода.

Первый ребёнок переводит строку в верхний регистр, второй
заменяет последовательности повторяющихся пробелов одним пробелом.
Обмен данными осуществляется через pipe. Необходимо
проверять ошибки, освобождать ресурсы и дожидаться завершения детей.

### Алгоритм решения

1. Родитель считывает одну строку с помощью `getline`, динамически выделяя буфер.
2. Создаёт три канала через `pipe` и два дочерних процесса через `fork`.
3. В дочерних процессах перенаправляет стандартный ввод и вывод через `dup2`,
   закрывает ненужные дескрипторы и запускает `child1` и `child2` через `execl`.
4. Передаёт строку по цепочке: родитель → child1 → child2 → родитель.
   `child1` применяет `toupper`, а `child2` удаляет лишние пробелы в исходном буфере.
5. Получает результат через `fdopen` и `getline`. Функция `WriteAll` обеспечивает
   передачу всех байт при частичной записи.
6. Закрывает каналы, получает статусы обоих детей через `waitpid`, выводит результат
   при успешном завершении и освобождает динамическую память.

### Ввод и вывод программы

Ввод: одна строка, длина которой не ограничена фиксированным буфером.
Вывод: строка в верхнем регистре без повторяющихся обычных пробелов.
Примеры приведены для латинских букв; преобразование кириллицы в UTF-8 не реализовано.

```text
Введите строку: aba   caba
Результат: ABA CABA
```

### Вывод

Реализована обработка строки двумя дочерними процессами с передачей данных через
три неименованных канала. Освоены создание процессов, перенаправление стандартных
потоков, управление дескрипторами и получение статусов завершения. Ожидание детей
через `waitpid` предотвращает сохранение зомби-процессов при штатном завершении.
